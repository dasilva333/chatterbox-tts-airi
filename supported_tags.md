# Chatterbox Supported Sound & Emotion Tags

When using Chatterbox, you can insert these tags in square brackets to trigger specific sounds or emotional performance. Note that the model is case-sensitive and requires the exact tag from the list below.

### Core Emotion tags
- `[laughter]` (Use this instead of [laughs])
- `[giggle]`
- `[guffaw]`
- `[sigh]` (Use this instead of [sighs])
- `[gasp]`
- `[groan]`
- `[cry]`
- `[mumble]`
- `[whisper]`

### Environmental & Physical Sounds
- `[meow]`
- `[bark]`
- `[howl]`
- `[sneeze]`
- `[cough]`
- `[clear_throat]`
- `[sniff]`
- `[snore]`
- `[chew]`
- `[sip]`
- `[kiss]`
- `[shhh]`
- `[humming]`
- `[singing]`
- `[music]`
- `[whistle]`
- `[exhale]`
- `[inhale]`
- `[gibberish]`

### Notes
- **Brackets**: Tags must be enclosed in `[]`.
- **Case Sensitivity**: Currently, the model prefers the lowercase versions listed above.
- **Turbo Support**: Some tags like `[chuckle]` may be supported by the Turbo model or via future updates, but the list above represents the verified vocabulary of the current baseline model.
